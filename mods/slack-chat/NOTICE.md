# Notice

`slack-chat` is the chat view of the Slack layout for Herdr.

- **Chat view**: based on Herdr Chat Plus (github.com/AIPIXZ/herdr-chat-plus), itself based on
  Herdr Chat (github.com/naruse/herdr-chat). MIT License, Copyright (c) 2026 naruse — see `LICENSE`.
  Changed for the Slack layout: threads, Slack-style messages and composer, loading glow,
  draft keeping, Escape to stop, waiting for a new Codex log, and more.
- **Quick first view of long conversations**: `bin/flockbook-modfeed`, the native sidecar of
  Flockbook (github.com/minchenlee/flockbook), included unchanged. MIT License,
  Copyright (c) 2026 Minchen Lee — see `bin/LICENSE-flockbook`. Built for macOS (Intel and Apple Silicon);
  elsewhere the chat skips it and reads the log the usual way.
